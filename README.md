# Figura-Santo-Personalizada
Diseño y fabricación de figuras del Padre Carlos Crespi mediante tecnología de impresión 3D. Las piezas se producen en distintos tamaños, manteniendo un alto nivel de detalle y acabado, ideales para uso devocional, decorativo o coleccionable.
